# Panel de Control — Heladería

Dashboard-first para llevar el control de una heladería de yoghurt griego en Los Cabos: ventas, gastos, inventario y documentos, todo en una sola pantalla.

🔗 **En vivo:** [control-heladeria-steel.vercel.app](https://control-heladeria-steel.vercel.app)

## Stack

- Next.js (App Router, Server Components, Server Actions)
- Supabase (Auth + RLS + Postgres + Storage)
- Tailwind v4

## Desarrollo local

```bash
npm install
npm run dev
```

Ver `.env.example` para las variables de entorno necesarias.
